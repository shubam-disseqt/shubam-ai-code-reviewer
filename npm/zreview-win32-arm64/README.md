# zreview-win32-arm64

Native binary for [zreview](https://www.npmjs.com/package/zreview) on
this platform. You do not install this package directly — it is pulled
in as an optional dependency of `zreview`:

```sh
npm install -g zreview
```

The binary is populated at release time from the matching GitHub
Release asset. See the [main repo](https://github.com/shubam-disseqt/z-code-reviewer)
for source, threat model, and provenance verification instructions.

Apache-2.0.
