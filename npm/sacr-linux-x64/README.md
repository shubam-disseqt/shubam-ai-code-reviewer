# sacr-linux-x64

Native binary for [sacr](https://www.npmjs.com/package/sacr) on
this platform. You do not install this package directly — it is pulled
in as an optional dependency of `sacr`:

```sh
npm install -g sacr
```

The binary is populated at release time from the matching GitHub
Release asset. See the [main repo](https://github.com/shubam-disseqt/shubam-ai-code-reviewer)
for source, threat model, and provenance verification instructions.

Apache-2.0.
