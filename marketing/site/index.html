What it does

A reviewer, not a chatbot with grep.

Most of zreview is deterministic Go. The LLM is a thin loop on top — and only pays when it earns its keep.

01

Deterministic engineering, thin LLM loop

Scanners, scoring, fingerprints, and the effort math all live in Go. The model gets a small, curated packet and has nowhere to hallucinate.

02

Two output modes

Bug findings for the humans, committable suggestions for the machines. Both flow through the same review pass — no double billing.

03

Every claim auditable

Effort table sums to the total. Depgraph edges are real imports. Findings link to line ranges. Nothing in the PR body is decorative.

Quick start

Four lines. That's it.

Install, point it at a PR, ship. Fits in a GitHub Action or your terminal.

terminalbash
# 1. install
brew install disseqt/tap/zreview

# 2. auth (one of)
export OPENAI_API_KEY="sk-…"

# 3. review a PR — bugs + suggestions posted inline
zreview review --pr 42 --format github --budget 0.02

# 4. or run in CI (drop this into .github/workflows)
uses: disseqt/zreview@v1
