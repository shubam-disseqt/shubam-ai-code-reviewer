## What's inside

| Page | What it covers |
|---|---|
| [CLI reference](/docs/reference/cli) | Every subcommand (`sacr version`, `sacr docs`, `sacr review`, `sacr index`, `sacr rules`, `sacr overlap`, `sacr doctor`), their flags, and the uniform exit-code contract. |
| [Configuration](/docs/reference/configuration) | Environment variables, the repo-local `.sacr.yaml` schema, the org-rules YAML schema, and precedence between all four layers. |
| [Providers](/docs/reference/providers) | The five built-in LLM presets (Anthropic, Bedrock, OpenAI Chat, OpenAI Responses, DeepSeek), model IDs, endpoint resolution order, and two-tier routing. |
| [Provider testing](/docs/reference/provider-testing) | 15-minute manual smoke protocols for each provider, code-path audit findings, and common-error tables. |

<Callout type="info">
Not every subcommand has shipped yet. Only `sacr version` and `sacr docs` are wired end-to-end today; the rest are documented against their locked target UX. Phase tags appear next to each subcommand on the [CLI reference](/docs/reference/cli) page.
</Callout>
