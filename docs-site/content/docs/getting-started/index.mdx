## What ships in the box

- One binary, `CGO_ENABLED=0` and `-trimpath` — no dynamic linker surface.
- Embedded local docs (`sacr docs`) — the same content you're reading now.
- Providers: Anthropic, OpenAI, AWS Bedrock, DeepSeek.
- Formatters: `stdout`, `json`, `github` (inline PR comments), `sarif` (Code Scanning).
