Installation

Distribution channels planned for Phase 9. Until then, build from source.

Build from source

git clone https://github.com/shubam-disseqt/z-code-reviewer.git
cd z-code-reviewer
make build
./bin/zreview version

Planned channels (Phase 9)

Supply-chain verification

Every release is attested via GitHub's SLSA build-provenance mechanism. Verify a downloaded binary with:

gh attestation verify --owner shubam-disseqt ./zreview-linux-amd64
