Quickstart

Once binaries ship (Phase 9), this is the shortest path to your first review.

Not yet functional. The full zreview review command lands in Phase 8. Today, only zreview version and zreview docs work end-to-end. See ROADMAP.md for phase status.

Install

curl -fsSL https://raw.githubusercontent.com/shubam-disseqt/z-code-reviewer/main/install.sh | sh

Configure a provider

export ANTHROPIC_API_KEY=...        # or OPENAI_API_KEY, or use Bedrock via the AWS credential chain

Optional: point at an index database

For repo-wide context and cross-PR overlap, provide a Postgres or local SQLite database:

export ZREVIEW_DB_URL="postgres://user:pass@host:5432/zreview?sslmode=require"
# or
export ZREVIEW_DB_URL="sqlite:///path/to/index.db"

Optional: point at an org rules repo

export ZREVIEW_ORG_RULES_REPO=disseqt/z-review-rules

Review the current diff

cd your-project
zreview review --from main --to HEAD --format json --output result.json

Post inline comments to a PR

zreview review --from main --to HEAD --format github --pr 42
