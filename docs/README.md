# sacr docs

Auto-deployed to GitHub Pages on push to `main` when anything under `docs/**` changes.

Public URL: https://shubam-disseqt.github.io/shubam-ai-code-reviewer/

These same HTML files are also embedded in the `sacr` binary and served locally via `sacr docs`.

Jekyll is disabled (`_config.yml` sets `theme: null`) so raw HTML/CSS is served untouched.
