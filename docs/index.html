shubam-ai-code-reviewer

AI-powered pull request review as a single Go CLI. Precise per-diff comments, repo-wide context, org-level rules, and cross-PR overlap.

Phase 2 skeleton. These docs are shipped with the binary. Only sacr version and sacr docs are wired end-to-end today. Review, indexing, rules, and overlap features are being built. See Architecture for the target design and the roadmap for phase status.

What it is

shubam-ai-code-reviewer is a self-hosted, Go-native CLI for AI code review. Core capabilities:

  • Precise per-diff comments anchored to hunk lines.
  • Repo-wide context via a persistent per-repo SQLite index.
  • Business rules at org level, authored as YAML in a git repo.
  • Cross-PR overlap and merge-conflict detection.

What it is not

No dashboard. No webhook server. No learning loop. No vulnerability scanning. No delegation mode. No plugin marketplace. Fixed scope on purpose — see Architecture § Non-goals.

Try it now

# from a clone
make build
./bin/sacr version
./bin/sacr docs
