z-code-reviewer

AI-powered pull request review as a single Go CLI. Precise per-diff comments, repo-wide context, org-level rules, and cross-PR overlap.

Phase 2 skeleton. These docs are shipped with the binary. Only zreview version and zreview docs are wired end-to-end today. Review, indexing, rules, and overlap features are being built. See Architecture for the target design and the roadmap for phase status.

What it is

z-code-reviewer is a self-hosted, Go-native CLI that combines the best of two Apache-2.0 open source projects into one tool:

FeatureSource of the approach
Precise per-diff commentsalibaba/open-code-review
Repo-wide context via a persistent indexmiracodeai/mira
Business rules at org level (YAML in git)Adapted from Mira custom_rules
Cross-PR overlap and merge-conflict detectionmiracodeai/mira

What it is not

No dashboard. No webhook server. No learning loop. No vulnerability scanning. No delegation mode. No plugin marketplace. Fixed scope on purpose — see Architecture § Non-goals.

Try it now

# from a clone
make build
./bin/zreview version
./bin/zreview docs
