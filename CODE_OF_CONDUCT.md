# Code of Conduct

## Expected behavior

- Assume good faith. Ask before assuming intent.
- Critique ideas, code, and decisions — not people.
- Keep discussion technical, concrete, and reversible.
- Disagree in public, cite sources, drop it when overruled.

## Unacceptable behavior

- Personal attacks, insults, harassment, or discriminatory remarks.
- Publishing others' private information without permission.
- Sustained disruption of technical discussion.
- Repeatedly re-opening settled decisions without new evidence.

## Scope

This code applies in all project spaces — GitHub issues and pull
requests, Discussions, code review threads, and any project-linked chat
or forum.

## Reporting

Report concerns to `conduct@disseqt.ai`. Reports are handled by project
maintainers and treated confidentially. If the concern involves a
maintainer, escalate to the project lead named in [GOVERNANCE.md](GOVERNANCE.md).

## Enforcement

Maintainers may take any action they judge appropriate, including
warning, temporary block, or permanent removal from project spaces.
Actions are recorded internally; the target and reporter are notified.
Appeals go to the project lead.
